# 自動開発

このゲームは、クラウドのAIが1時間おきに、1回で3件まで作り足しています。
進み具合は [進み具合ページ](https://ryoseiimai.github.io/ryoseiworld-game/devlog/) で見られます。
やってほしいことは [要望を書く](https://github.com/Ryoseiimai/ryoseiworld-game/edit/main/autodev/REQUESTS.md) に1行で足してください。
本番の入れ替えは [やることリスト](ROADMAP.md) の「要GO」の行で止まり、今井さんの「GO」の後は司令塔が入れ替えます。
全部止めたいときは、このフォルダに `STOP` という空のファイルを作ってください。
