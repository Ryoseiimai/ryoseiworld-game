# 第1段の実装・検証記録

成果物: `v5/index.html`。CSS/JavaScriptを内包し、同じ `v5/assets/` 配下の素材だけを読み込む。外部ライブラリ・外部リクエストなし（ホストから注入されたSDKの保存機能を除く）。既存の `index.html` / `rpg.html` は未変更。commitなし。

## 実装

- タイトル、夏の夜のプロローグ、相棒の命名、召喚チュートリアル、探索、章クリアとタイトル復帰。
- ヒダマリちょう、自分の部屋、コンビニ、でんきやの4マップ。町の14人＋店員・修理屋の16キャラクター。看板、学校、図書館、自販機、ベッド、PCなどの調査。
- 町の3種の敵、経験値・レベル・お金、商品3種と無料充電、ナオスライム・コードラゴン、BUG KING。
- rpg.html由来のHPドラムロール（45ms/目盛り）、タイプライター、Web Audio、SDK/localStorageアダプター。4曲のオリジナル音列。
- セーブはソラへの会話、メニュー、チュートリアル・加入・章クリアの節目。AI名はSDKへ送らず端末内のみ。SDK保存フィールドを第1段の進行情報に拡張。
- ドラッグの仮想スティック、矢印/WASD、Z/Enter、X/Esc、ひとやすみ。540×960を縦横比維持で中央配置。
- GAME_DATAに地形グリッド、配置、会話、召喚獣、敵数値・行動、道具、章のイベントと曲を集約。
- 透過PNGの最下部16％を走査して足元の衝突帯を生成。オブジェクトのcolliderで上書き可能。描画は足元Y順。
- 素材が空でも仮絵で動作。未完成の素材群は15秒おきに同じ相対JSONを再確認し、到着したPNGへ切り替える。今回は指定6素材群がすべて到着。既存のryoseiとbugkingをv5/assetsへコピー済み。

## 再実行

作業フォルダで `node tools/test_v5.cjs` を実行。結果は `v5/verification/node-results.txt` に出力。

テストはNode VMでDOM・Canvas・Web Audio・SDKの代替を使う。衝突判定の入力には実際のPNGをNodeのzlibで復号し、そのアルファ値を使っている。マップ移動の一部にはdebugWarpを使うが、主経路のチュートリアル、通常戦、BUG KINGは通常コマンドで勝利させている。debugWinは素材未到着ケースの遷移確認だけに使用。

確認した内容:

- タイトル→プロローグ→命名→ナオスライム召喚→部屋→町→NPC会話→接触戦闘→コンビニ入店・買い物・充電→でんきや入店→加入→コードラゴン召喚→ボス勝利→つづく→タイトル。
- 通常戦5回の経験値でボスに勝利。画面遷移、入出店、向きを合わせた会話、残金・道具・電池の増減。
- リロード相当の別VMで「つづきから」。章、位置、HP、レベル、経験値、電池、お金、道具、召喚獣、ボス撃破の復元。
- 致死ダメージのロール途中で回復、電池不足では消費・ターン進行なし、敗北時に最後の保存へ復帰。
- 高レベル時の接触勝利、ドラッグ移動とキャンセル、手動・ホスト一時停止、SDK音声OFF/ON。
- 390×844、1280×720、800×800の中央配置変換を実行し、状態が失われないこと。
- 全素材なしの仮絵、後から素材を読み込んだときの差し替え、実PNGの足元判定で全イベント・NPC・出口に到達できること。
- SDKの読込待ち・保存フィールド・名前除外・ready順序、localStorage利用不可への対応。
- Node構文解析、保護対象2ファイルの差分ゼロ。

## 検証できなかったこと

- Playwrightは実行ツールとページ遷移ツールの両方が「MCP tool call requires approval, but approval policy is never」で拒否された。ローカルHTTPサーバーのbindもOperation not permitted。ブラウザの実機表示、スクリーンショット、実ブラウザでのconsole error 0は未検証。
- 上記3サイズの検証は座標変換と状態の自動確認であり、ブラウザによる文字折り返しや画面崩れの目視確認ではない。
- 本物のYouTube Playables SDK環境、実スピーカーからの音、実端末の指操作、人が普通に遊ぶ10〜15分の所要時間は未確認。
- 依頼台帳のaddは~/.irai/events.jsonlへの書き込みが権限外で失敗。irai renderも~/.irai/依頼台帳.local.md.tmpへの保存が権限外で失敗。ObsidianのDaily/セッションログも今回の書き込み許可範囲外なので変更していない。このファイルを作業記録として残す。
